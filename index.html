KL Reimagined: Immersive VR Tour of Kuala Lumpur attractions

A standalone VR experience for Meta Quest 3 that lets users explore Kuala Lumpur’s landmarks, the Petronas Twin Towers, KL Tower and Muzium Negara through guided mini-tasks. Built in Unity with C#.

  • Built three locomotion modes — teleportation, joystick movement and waypoint navigation, to suit different VR comfort levels
  • Scripted interactive mini-tasks in C#, including snap-to-grid block building with structure validation and an animal catch-and-release activity
  • Modelled and optimized the landmarks through iterative remodelling and proximity-based spawning to sustain performance on standalone hardware
  • Designed info panels and spatial audio triggered by task progress to deliver landmark facts in context
  • Added environmental polish with trigger-based automatic doors and a rotating skybox

Theatre MBA – Cinema Ticketing & Booking Platform

A full-stack cinema booking system built with Laravel, rebuilt from an older PHP project to handle real-world problems like double-booked seats and safe cancellations.

  • Architected an 8-table relational schema in MySQL, separating showtimes from seats so screening data is stored once rather than duplicated across every seat row
  • Designed a cancellation system using a MySQL stored generated column with a NULL-aware unique index, letting cancelled seats return to sale while preserving a complete booking audit trail
  • Built a role-based admin panel with sales reporting, CSV export, and an all-or-nothing bulk CSV import that validates every row before writing, preventing partial or corrupted schedules

Healthy vs Unhealthy: Behaviour-Based Health Status Predictor

A machine learning system that predicts whether a person is healthy or unhealthy from 12 daily lifestyle habits, trained on a 500-response survey. Random Forest classifier with 92% accuracy on unseen data, served through an interactive Streamlit web app.

  • Designed and ran a bilingual (English/Malay) Google Forms survey, collecting 500 responses on sleep, diet, exercise, stress and other daily habits
  • Built a data cleaning pipeline in pandas that corrects entry errors, handles missing answers and encodes categorical responses with explicit, ordered mappings
  • Compared seven classification algorithms using stratified 10-fold cross-validation, then tuned a Random Forest across 72 hyperparameter combinations with grid search
  • Achieved 92% accuracy on a held-out test set using behaviour features alone, matching the accuracy of BMI as a predictor
  • Built the model as a Streamlit web app with a guided input form, confidence scores and a model explanation panel
  • python
  • random forest
  • scikit-learn
  • pandas
  • seaborn
  • streamlit
